# Portfolio: System & UX Analysis Case Studies

В этом репозитории представлены результаты глубокого анализа бизнес-процессов и пользовательских сценариев. Кейсы основаны на реальных данных (выборки более 1600+ тикетов) и включают расчеты ROI.

## Ключевые компетенции, продемонстрированные в проектах:
- **Анализ данных:** Работа с большими массивами обращений, сегментация причин боли.
- **Проектирование систем (AS-IS / TO-BE):** Реинжиниринг процессов для снижения операционных затрат.
- **UX/UI Аналитика:** Применение эвристик Нильсена и анализ когнитивной нагрузки.
- **Бизнес-валидация:** Расчет окупаемости (ROI), влияние на метрики NPS и LTV.

---

### Проект 1: Устранение информационных разрывов в B2B-поддержке
**Файл:** `Анализ пользовательских сценариев.pptx`
* **Проблема:** Юридические лица перегружают поддержку вопросами об оплате с «Баланса средств» из-за отсутствия системных уведомлений.
* **Стек:** SQL (выборка), Excel (анализ 1600+ тикетов), BPMN (проектирование логики подсказок).
* **Результат:** Экономия 1.2 млн ₽/год за счет автоматизации селф-сервиса (рост до 92%).

### Проект 2: Оптимизация архитектуры личного кабинета (FinTech)
**Файл:** `Оптимизация информационной архитектуры.pptx`
* **Проблема:** Нарушение видимости статуса системы — пользователи не видят зачисления средств после активации сертификатов.
* **Решение:** Изменение информационной архитектуры раздела «Финансы», внедрение динамических виджетов.
* **Результат:** Прогноз роста конверсии на 15-20% за счет снижения «тревожности» пользователя.

### Проект 3: Борьба с Dark Patterns в подписочных сервисах
**Файл:** `Оптимизация процесса активации платных подписок.pptx`
* **Проблема:** Репутационные риски и высокая стоимость обработки жалоб из-за «скрытого» подключения услуг.
* **Решение:** Внедрение Confirmation Step и проектирование прозрачного флоу активации.
* **Результат:** Снижение обращений по «несанкционированным списаниям» на 40-60%.
